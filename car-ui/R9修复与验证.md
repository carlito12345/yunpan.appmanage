# R9 局域网互传二维码修复

修复用户截图中的“文件管理 → 文件互传 → 局域网互传”二维码缩成顶部小点的问题。它使用 dialog_share，与此前的云盘登录二维码、公开来源海报是不同布局。

## 原因与改动

通用布局将 v_qrCode 视为覆盖层，原约束布局的0dp宽度在重排后失去有效尺寸。此次为互传弹窗单独布局，将原ImageView放进有界方形白底区：竖屏上下排，横屏左右排；说明区滚动，原提示音和返回固定在底部。

保留原 v_root2 ConstraintLayout、二维码ImageView、Guideline、说明/地址文字、提示音及其图标、返回控件的实例与ID。二维码生成、URI绑定、地址和原监听器不修改。图片缺失时保持原GONE状态和手动地址，不强行显示空白二维码；后到图片继续使用原实例。共享QrSquare测量遵守明确高度约束，已有云盘大二维码回归仍通过。二维码使用FIT_CENTER，无滤色、白底不随主题透明度淡化。
