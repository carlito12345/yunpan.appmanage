# 应用管家 · 车机定制版 R9 / P1 更新日志

更新日期：2026年11月4日  
定制作者：carlito

本次更新围绕车机操作、大屏布局和个性化外观展开，汇总本轮定制新增与调整内容。

## P1 包名定制与新图标

- 增加 `com.maxinf.car` 定制包，兼容版和 AES 加固版均换为用户提供的 `gj_ico.jpg` 启动图标。
- 增加 Windows 一键改包名入口，可选择新版基础 APK、批量输入其他包名及替换图标，自动生成签名安装包和校验报告。
- 同步调整 Provider、权限、广播标识和加固绑定，保留原代码命名空间、JNI及原生启动参数兼容逻辑。
- 源码放在 `variants/package-customization` 分支；私钥和本机配置不入仓库。
- 5项新增测试通过；Android11 VM 使用临时包名验证图标、启动及首页横竖屏，原有同名车机应用保留。详情见 `PACKAGE_VARIANTS.md`。

## R9 追加修复：局域网互传二维码

- 修复“文件管理 → 文件互传”中二维码缩成顶部小点的问题。
- 二维码使用独立的大尺寸方形白底区域，竖屏上下排布，横屏左右排布。
- 说明文字可滚动，文件接收提示音和返回按钮固定保留。
- 保留原二维码内容、手动访问地址及原有操作回调。
- Android11测试VM上的横竖屏截图均已通过离线解码核对；未进行实际文件传输。

## 界面与屏幕适配

- 重新设计首页、功能目录、文件管理、网络存储、设置及多类子页面和弹窗。
- 面向1440×1920竖屏优化，同时支持横屏布局，随当前窗口调整空间分配。
- 设置采用分区分级布局，按显示、安装、连接和高级选项组织，减少长列表堆叠。
- 优化导航、主题按钮、工具栏、表单和列表的文字位置、间距与操作区域。

## 可编辑的常用首页

- 自行添加常用应用、内置功能和自定义跳转入口。
- 支持修改入口名称、移除入口、调整位置及长按拖动排序。
- 保留快捷添加入口，方便把高频操作集中到首页。

## 文件与网络存储

- 网络存储参考MT管理器改为左右双窗，云端与本地各自保留存储选择、路径和文件列表。
- 调整文件条目的名称、时间、大小与选中状态展示。
- “添加云端连接”类型按钮横向排列，随可用空间自动换行。
- 放大云盘登录二维码，保留完整白色识别区域，关闭操作固定可见。
- 继续沿用原有文件和云盘业务，主要更新操作界面与布局。

## 多款主题与外观设置

- 新增暖橙奶油、冰蓝荧光科技、黑白墨镜阴影三款主题，支持日间和夜间切换。
- 主题中心新增0–100%全局面板透明度，文字、图标和壁纸不随面板整体淡化。
- 新增纯色包边、多彩渐变和流光飞舞边框，可选冰蓝、霓虹紫、暖金、薄荷、樱粉、银白主色。
- 外观调整支持预览、取消、应用和恢复默认；切换主题或日夜模式时会同时应用当前外观草稿。
- 流光边框在界面隐藏时停止续绘，系统关闭动画时以静态效果显示。

## 统一壁纸中心

- 将静态图片、视频壁纸和代码绘制的动态粒子集中到同一页面。
- 原装星月入口调整为静态壁纸选择入口，可直接进入“修改管家背景”；原装背景仍可恢复。
- 静态图片新增按当前屏幕比例裁切，支持拖动、双指缩放和重置，横竖屏使用对应比例。
- 裁切另存，不改动原图；返回预览后点击应用才保存设置。
- 视频壁纸支持静音循环与居中铺满，离开应用时释放播放资源。
- 粒子壁纸提供六款样式、多款前景与背景色，以及速度、密度和节能设置。
- 去除静态、视频、粒子及原装背景共用的泛白、压暗与主题混色遮罩，恢复壁纸本身色彩。
- 提高已裁切图片的解码清晰度，减少二次缩小造成的模糊。

## 弹窗与操作体验

- 增加磨砂背景板及底层压暗，帮助区分当前弹窗与下层页面。
- 多类弹窗改为有界内容区和固定操作区，减少横屏时按钮被裁切或挤出的问题。
- 调整文件操作、自动化映射、下载和设置等页面的空间分配，减少图标、文字及控件错位。

## 使用说明

- 透明度调整的是界面面板；弹窗磨砂与底层压暗仍会保留，壁纸本身不再叠加泛白遮罩。
- 加固可提高静态分析门槛，运行时代码仍可能被提取，不承诺绝对防反编译。
- 已通过59项本地回归，并在Android11测试VM验证加固版启动、首页、功能目录、主题和来源页横竖屏显示；完整云盘、root/ADB、自动化业务及实车仍需按设备验证。
- 更新后偶发首次返回桌面、再次打开可进入首页的既有现象仍在记录中。
