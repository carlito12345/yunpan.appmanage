# R6 壁纸中心与屏幕裁切验证

进入：左下角 **主题 → 壁纸中心**，或 **设置 → 高级 → 修改管家背景>>**。静态分区改为“选择静态壁纸 · 按屏幕裁切”；默认星月另用“恢复默认星月”。支持本地静态图片、原有自定义背景、纯色、视频和六款粒子壁纸，六种粒子颜色、六种底色。原 APK 唯一内置星月图 `bj_2` 原字节保留。

选择图片后读取当前 owner 屏幕像素，裁切框与屏幕比例一致。支持拖动、双指缩放、重置和方向键/加减键；旋转时保留相对缩放和中心并重新约束。1440×1920/1920×1440按对应像素输出；超大屏保持比例，最长边2560、约400万像素上限。裁切保存私有 JPEG 副本，原图只读；“使用裁切”回到预览，点击“应用壁纸”才保存。取消清理未应用的副本，已保存图片与原 bj.png/jpg 受保护。

视频为本地静音循环、居中填满，离开应用释放播放资源；节能模式显示首帧。粒子包括星河漂移、连线星网、流萤波纹、轻雪漫游、轨道光环、流星雨，可调速度/密度/显现强度。这些是管家内部背景，不是系统 WallpaperService。

保留 R5 磨砂弹窗/底层压暗及子页修复、可编辑主页和自定义跳转、三主题/日夜、横竖屏和分区设置。磨砂为 owner 内存快照模糊，独立 Surface 内容不保证进入快照。
