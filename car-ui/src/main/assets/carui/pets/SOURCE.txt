Floating-button art supplied in the workspace resource folder:
小熊.zip, 小棕熊.zip, 小狗.zip, 动态悬浮图标黑白小熊猫.zip

The five PNG frames in each archive retain their order and transparency.
Each set shares a single crop and scale so the art stays aligned while playing.

The grok directory contains animated sprites rendered from TyCoding's Grok Ball.
See grok/SOURCE.txt and grok/LICENSE.txt for the pinned source and MIT notice.

The five starray-*.png files use the original 512 × 512 cells from Starray Voice's
cn-test/src/main/res/drawable-nodpi/star_avatar_atlas.png by carlito.
The top row provides 光灵, 绒星 and 水晶舱. The first two cells of the bottom
row provide 银翼 and 星云. The assets keep their source alpha and use the
same native Android face and motion layer.
