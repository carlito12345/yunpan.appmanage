# R13 design documentation

Scope: restore the original SU command and ADB shell password fields in Settings and make wireless pairing input understandable and usable. This is an ordinary extension of the approved personal control console. `DESIGN.md` and `.impeccable/design.json` are preserved; no new shared token, visual world or image asset is introduced. R11 palette, component-role radii and favorite-heading/card rules remain. The R12 Android 9 loader path is retained, with a narrow authenticated app_process bootstrap correction recorded below.

## Source and component record

- `LegacyUi.settings` retains four persistent sections and the original settings widgets. Recognized nonnumeric label/input rows place the wrapping label above a full-width original `EditText`; the advanced field grid still uses two columns at 600dp and above. SU and shell password receive distinct content descriptions and hints, without rewriting their values or original edit/save callbacks.
- Settings → 连接 now has a labeled `无线调试配对助手` entry. It dismisses Settings and opens the original pairing-input Activity directly, leaving the original tool's root gate intact.
- `CarUi` retains 19sp normal inputs, 54dp minimum height, 18dp horizontal / 10dp vertical padding and 18dp field corners. The SU, shell-password and pairing-code fields request a 1dp outline under the default appearance, with the existing 2dp ink focus/pressed treatment. Configured edge effects remain available.
- `AdbPairUi` recomposes the existing guide and input layouts around original `et_pair`, confirm, return and status widgets. The code is centered at 26sp. Six ASCII digits are validated as text, preserving a leading zero. Incomplete/invalid codes disable confirm; the existing button text gates resubmission while its original asynchronous callback is busy. Clipboard reading happens only on the explicit paste action; whitespace is removed and only a six-digit result replaces the code.
- The finish correction keeps initial, in-progress and success status text in the current theme's ink. A status `TextWatcher` reapplies color after original asynchronous updates; recognized failure text containing 失败, 错误 or 未找到 uses the existing day/night danger role. This is a local semantic correction, not a new palette rule or token.
- The novice guide distinguishes the system pairing code, automatically discovered pairing port, connection port, legacy 5555 port and SU/shell password. It explains Wi-Fi, keeping the system code window open, returning to inspect status and retrying with a new code. Original guide controls and their listeners remain, including compatibility/input routes. Android 11 is required for the new system-code route; older systems receive network-ADB/USB guidance.
- The assistant now exposes `通知栏输入并打开设置` before the overlay action. It closes any assistant overlay, starts the original `AdbPairService` as a foreground service, then opens Developer Settings. A `停止配对通知` action becomes visible after starting the service; it requests `stopService`, hides the action and reports that state or a failure. The instructions explain keeping the system code dialog open, expanding the notification and submitting its six-digit input. Failure text points to notification permission or the original manual small-window route. This fallback reuses original notification/service behavior; it does not bypass protected system-window policy.
- The floating input is a permission-gated `TYPE_APPLICATION_OVERLAY`, carrying the same original input/control/status instances. Its solid current-theme surface, 26dp corners and thin outline prioritize readability over app-panel transparency. The body scrolls within a bounded height; its title can be dragged, its body collapsed and its window closed. The final header places 8dp between Collapse/Expand and Close while retaining the drag title and existing touch-sized controls. Source handles acquiring input focus, outside/Back focus release, restoring input on Close, owner-destruction cleanup and display-bound resizing. The actual runtime subset is recorded below.
